11月11日开始，11月18日基本功能完善
环境准备与抓包尝试（11月11日）
尝试了windows和linux环境下的环境搭建，最后选择了windows下进行实验，搭建了Npcap与python虚拟环境，编写最小化抓包脚本，成功抓取到数据包，完成贯通。
协议解析程序开发（11月12日）
基于基础运算完成二进制字节流解析逻辑，完成以太网、ipv4、tcp/udp的逐层解析，形成packet_parser.py和2_parser_test.py。
GUI骨架与多线程抓包（11月14日 - 11月15日）
基于PySide6搭建UI，并解决抓包阻塞UI的性能问题，实现了三栏视图布局，形成3_gui.py、4_gui.py。
展示功能完善（11月17日）
完善协议详情树展示功能，实现十六进制高亮、增加了颜色区分等内容，形成5_gui.py。
Tcp流追踪与网卡波形监控（11月18日）
实现 TCP 流追踪加分项，以及全局网卡实时流量监控。利用五元组双向哈希还原 TCP 会话；通过轻量级后台线程驱动下拉框波形图；完成标准 Pcap 文件导出，形成day6_gui.py、test_ifaces.py。
最后功能完善和bug调整阶段（11月19日 - 11月20日）
完善过滤和BPF预编译功能、完善回环抓包故障、虚拟机网卡不显示等问题。形成packet_parser.py和main.py
